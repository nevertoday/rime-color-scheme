# XXD Color Schemes for Rime

[Squirrel](https://github.com/rime/squirrel) / [Weasel](https://github.com/rime/weasel)용 **선택 칩 배색 20세트**. 각 세트에 라이트와 나이트가 있습니다.

선택 칩은 다시 칠하지 않습니다. 공개된 브랜드 HEX를 씁니다. 티파니 상자 `#81D8D0`, 에르메스 오렌지 `#F37021`, 클라인 블루 `#002FA7`, 샤넬 블랙 `#000000`. 라이트는 종이, 나이트는 거의 검정. MIT.

## 테마 미리보기

20가지 테마의 라이트와 나이트 효과를 보여드립니다. 먼저 마음에 드는 색상을 고른 뒤 AI 명령이나 수동 절차로 설치하세요.

## 수동 설치

Squirrel이 읽는 파일은 `~/Library/Rime/squirrel.custom.yaml`뿐입니다. `xxd_*`를 **이 파일에 복사**하세요. 심볼릭 링크와 `__include`는 쓰지 마세요.

### macOS · Squirrel

1. 메뉴 막대 Squirrel 아이콘 → **사용자 설정…** 으로 `~/Library/Rime/`을 엽니다. `squirrel.custom.yaml`이 없으면 만들고, 루트는 `patch:`여야 합니다.
2. 이 저장소의 [`schemes/xxd.squirrel.yaml`](schemes/xxd.squirrel.yaml)을 엽니다.
3. `preset_color_schemes:` 아래 `xxd_*`를 복사합니다. 한 세트면 라이트+나이트 한 쌍(`xxd_tiffany`와 `xxd_tiffany_night`). 여러 세트면 쌍으로. 전부면 모든 `xxd_*`.
4. `squirrel.custom.yaml`의 `patch:` → `preset_color_schemes:` 아래에 붙입니다. **기존 다른 스킨과 app_options는 유지.**
5. `patch:` 아래에 지금 쓸 쌍을 적습니다:

```yaml
patch:
  style/color_scheme: xxd_tiffany
  style/color_scheme_dark: xxd_tiffany_night
```

6. Squirrel 메뉴 → **다시 배포**. 시스템 라이트/다크가 이 쌍을 씁니다. 바꾸려면 아래 표의 키로 고치세요.

### Windows · Weasel

같은 절차입니다. 파일은 `%APPDATA%\Rime\weasel.custom.yaml`, 배색은 [`schemes/xxd.weasel.yaml`](schemes/xxd.weasel.yaml) (색은 BGR). Weasel 메뉴에서 다시 배포.

## AI에게 맡길 때 복사할 말

아래 블록을 Cursor / Claude / ChatGPT / Grok에 그대로 붙이세요. 배색 이름과 `xxd_` 키만 원하는 것으로 바꾸면 됩니다. **심볼릭 링크와 `__include` 금지.**

### 전부 설치하고 티파니 사용

```
https://github.com/nevertoday/rime-color-scheme 에서 macOS Squirrel에 XXD 배색을 모두 설치해 주세요.
심볼릭 링크 금지. __include 금지.
schemes/xxd.squirrel.yaml의 모든 xxd_*를 ~/Library/Rime/squirrel.custom.yaml의 patch.preset_color_schemes에 합치세요.
기존 다른 스킴, app_options, 다른 patch 키는 유지.
설정:
style/color_scheme: xxd_tiffany
style/color_scheme_dark: xxd_tiffany_night
그다음:
"/Library/Input Methods/Squirrel.app/Contents/MacOS/Squirrel" --reload
끝나면 쓴 xxd_ 키를 나열하세요.
```

### 한 세트만 (이름과 키를 바꾸세요)

```
macOS Squirrel에 XXD 배색 「티파니 블루」만 설치해 주세요.
저장소: https://github.com/nevertoday/rime-color-scheme
schemes/xxd.squirrel.yaml의 xxd_tiffany와 xxd_tiffany_night만 ~/Library/Rime/squirrel.custom.yaml의 preset_color_schemes에 넣으세요.
심볼릭 링크 금지, __include 금지, 기존 다른 배색은 지우지 마세요.
사용:
style/color_scheme: xxd_tiffany
style/color_scheme_dark: xxd_tiffany_night
그다음 Squirrel --reload.
```

### 여러 세트 넣고 하나만 켜기

```
https://github.com/nevertoday/rime-color-scheme 의 schemes/xxd.squirrel.yaml에서
다음을 ~/Library/Rime/squirrel.custom.yaml에 복사:
xxd_hermes, xxd_hermes_night, xxd_klein, xxd_klein_night, xxd_chanel, xxd_chanel_night
에르메스 사용:
style/color_scheme: xxd_hermes
style/color_scheme_dark: xxd_hermes_night
심볼릭 링크 금지, __include 금지, 다른 설정은 유지. Squirrel 배포:
"/Library/Input Methods/Squirrel.app/Contents/MacOS/Squirrel" --reload
```

### 이미 설치됨. 쓰는 세트만 바꾸기

```
~/Library/Rime/squirrel.custom.yaml에 이미 xxd_*가 있습니다.
쓰는 쌍만 클라인 블루로 바꾸세요:
style/color_scheme: xxd_klein
style/color_scheme_dark: xxd_klein_night
그다음 Squirrel --reload. preset_color_schemes는 건드리지 마세요. 심볼릭 링크 금지.
```

## 이 저장소의 역할

여기는 배색 팩과 미리보기입니다. 실제로 동작하는 설정은 내 컴퓨터의 `squirrel.custom.yaml`입니다. 여기서 YAML을 고치면 사용자 폴더에 다시 복사하고 배포하세요.

이케아 옐로와 샤르트뢰즈는 흰 지면에서 사라지므로, 라이트는 네이비 / 카키 바로 본색 칩을 받칩니다. 샤넬 나이트는 차콜 바 + 검정 칩 + 아이보리 글자. 글자색: 어두운 칩은 흰색, 밝은 칩은 같은 계열 잉크(티파니 `#0A7680`, 코랄 `#742C25`, 밀레니얼 `#783639`).

미리보기는 `python3 scripts/render_previews.py`가 YAML에서 생성합니다. 손으로 그리지 마세요.

## 고지

색은 공개된 시그니처 컬러와 흔한 디지털 근사값이며, 개인 IME 테마용입니다. **각 브랜드와 소속·라이선스 관계는 없습니다.** 이름은 색을 구분할 때만 씁니다.
