# XXD Color Schemes for Rime

给 [鼠须管](https://github.com/rime/squirrel) / [小狼毫](https://github.com/rime/weasel) 用的 **20 套选中色**。每套浅色 + 夜色。

选中块不调色，用的是公开记载的品牌 HEX：蒂芙尼盒子 `#81D8D0`、爱马仕橙 `#F37021`、克莱因蓝 `#002FA7`、香奈儿黑 `#000000`。浅色是纸，夜色是接近黑的底。MIT。

## 主题效果预览

下面展示 20 套主题的浅色与夜色效果。先选一套喜欢的配色，再复制 AI 指令完成安装，或按手动步骤配置。

## 这个仓库做什么

本仓库是配色包和预览图。真正生效的是你机器上的 `squirrel.custom.yaml`。改完本仓库里的 YAML 后，再拷一次到用户目录并部署。

宜家黄、酸橙绿铺在白纸上会看不见，浅色用海军蓝条 / 卡其条去衬原色块。香奈儿夜色是炭黑条 + 黑块 + 象牙字。字色：深色块配白字，浅色块配同色系墨（蒂芙尼 `#0A7680`，珊瑚 `#742C25`，千禧 `#783639`）。

预览图与 YAML 配色文件一并保存在仓库中，方便先看效果再选择主题。

## 首选：让 AI 一次完成

如果你正在使用 Cursor、Claude、ChatGPT、Grok 等 AI 工具，直接复制 [`prompts/zh.md`](prompts/zh.md) 里的指令，告诉 AI 你的系统和想用的配色即可。AI 会把配色合并到 Rime 配置、保留已有设置，并完成重新部署。

安装全部配色并启用蒂芙尼蓝，可以直接使用：

```text
请根据 https://github.com/nevertoday/rime-color-scheme 安装全部 XXD Rime 配色。
我是 macOS 鼠须管用户；请读取 schemes/xxd.squirrel.yaml，把所有 xxd_* 方案合并到 ~/Library/Rime/squirrel.custom.yaml。
保留我已有的其它配色、app_options 和其它 patch 设置，不要软链接，不要 __include。
启用蒂芙尼蓝：xxd_tiffany；深色模式：xxd_tiffany_night。
完成后重新部署，并列出实际写入的 xxd_ 配色键。
```

只想换正在使用的配色时，复制这条指令并替换名称和键：

```text
我的 Rime 配置里已经安装了 XXD 配色，请只把当前配色切换为克莱因蓝：
style/color_scheme: xxd_klein
style/color_scheme_dark: xxd_klein_night
不要修改 preset_color_schemes，不要删除其它设置。完成后重新部署。
```

Windows 小狼毫用户，把上面指令中的平台改为 Windows，并让 AI 使用 `schemes/xxd.weasel.yaml` 和 `%APPDATA%\\Rime\\weasel.custom.yaml`。

## 手动安装

鼠须管只读 `~/Library/Rime/squirrel.custom.yaml`。把本仓库的 `xxd_*` **拷进这个文件**。不要软链接，不要 `__include`。

### macOS · 鼠须管

1. 点菜单栏鼠须管图标 → **用户设定…**，打开 `~/Library/Rime/`。没有 `squirrel.custom.yaml` 就新建一个，最外层必须是 `patch:`。
2. 打开本仓库 [`schemes/xxd.squirrel.yaml`](schemes/xxd.squirrel.yaml)。
3. 复制 `preset_color_schemes:` 下面的 `xxd_*` 块：只要一套就复制浅色+夜色一对（例如 `xxd_tiffany` 和 `xxd_tiffany_night`）；要多套就成对多复制；要全部就把所有 `xxd_*` 都复制。
4. 粘贴到 `squirrel.custom.yaml` 的 `patch:` → `preset_color_schemes:` 下面。**保留你原来的其它皮肤和 app_options。**
5. 在 `patch:` 下写上正在用的一对：

```yaml
patch:
  style/color_scheme: xxd_tiffany
  style/color_scheme_dark: xxd_tiffany_night
```

6. 鼠须管菜单 → **重新部署**。系统浅色/深色会自动换这一对。换套就把两个名字改成下表里的键。

### Windows · 小狼毫

同样步骤，文件换成 `%APPDATA%\Rime\weasel.custom.yaml`，配色从 [`schemes/xxd.weasel.yaml`](schemes/xxd.weasel.yaml) 拷（颜色仍是 BGR）。然后小狼毫菜单 → 重新部署。

## 让 AI 帮你装（可复制话术）

把下面整段发给 Cursor、Claude、ChatGPT、Grok 即可。把配色名和 `xxd_` 键换成你要的。**禁止软链接和 `__include`。**

### 装全部，并启用蒂芙尼

```
请根据 https://github.com/nevertoday/rime-color-scheme 给 macOS 鼠须管安装全部 XXD 配色。
不要软链接，不要 __include。
从仓库 schemes/xxd.squirrel.yaml 取出所有 xxd_* 方案，合并进 ~/Library/Rime/squirrel.custom.yaml 的 patch.preset_color_schemes。
保留我已有的其它方案、app_options 和其它 patch 键。
设置：
style/color_scheme: xxd_tiffany
style/color_scheme_dark: xxd_tiffany_night
然后执行：
"/Library/Input Methods/Squirrel.app/Contents/MacOS/Squirrel" --reload
做完列出写入了哪些 xxd_ 键。
```

### 只装一套（把名字和键换成你要的）

```
请给 macOS 鼠须管只安装 XXD 配色「蒂芙尼蓝」。
仓库：https://github.com/nevertoday/rime-color-scheme
只要 schemes/xxd.squirrel.yaml 里的 xxd_tiffany 和 xxd_tiffany_night，写入 ~/Library/Rime/squirrel.custom.yaml 的 preset_color_schemes。
不要软链接，不要 __include，不要删除我现有的其它配色。
启用：
style/color_scheme: xxd_tiffany
style/color_scheme_dark: xxd_tiffany_night
然后 Squirrel --reload。
```

### 装多套，启用其中一套

```
请从 https://github.com/nevertoday/rime-color-scheme 的 schemes/xxd.squirrel.yaml
把这些方案拷进 ~/Library/Rime/squirrel.custom.yaml：
xxd_hermes, xxd_hermes_night, xxd_klein, xxd_klein_night, xxd_chanel, xxd_chanel_night
启用爱马仕：
style/color_scheme: xxd_hermes
style/color_scheme_dark: xxd_hermes_night
不要软链接，不要 __include，保留其它配置。然后部署鼠须管：
"/Library/Input Methods/Squirrel.app/Contents/MacOS/Squirrel" --reload
```

### 已经装过，只换正在用的一套

```
我的 ~/Library/Rime/squirrel.custom.yaml 里已经有 xxd_* 配色。
请只改正在用的，换成克莱因蓝：
style/color_scheme: xxd_klein
style/color_scheme_dark: xxd_klein_night
然后 Squirrel --reload。不要改 preset_color_schemes，不要软链接。
```
