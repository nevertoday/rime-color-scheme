# XXD Color Schemes for Rime

**٢٠ لوحة لشريحة التحديد** لـ [Squirrel](https://github.com/rime/squirrel) (macOS) و [Weasel](https://github.com/rime/weasel) (Windows). لكل منها وضع فاتح وليلي.

شريحة التحديد لا تُعاد تلوينها. نستخدم قيم HEX المنشورة: علبة تيفاني `#81D8D0`، برتقالي هيرميس `#F37021`، أزرق كلاين `#002FA7`، أسود شانيل `#000000`. الفاتح ورق، والليلي قريب من الأسود. MIT.

## معاينة السمات

نعرض هنا تأثيرات 20 سمة في الوضع الفاتح والليلي. اختر لوحة أولاً، ثم استخدم تعليمات الذكاء الاصطناعي أو خطوات التثبيت اليدوي.

## تثبيت يدوي

Squirrel يقرأ فقط `~/Library/Rime/squirrel.custom.yaml`. **انسخ** كتل `xxd_*` إلى هذا الملف. لا رابط رمزي ولا `__include`.

### macOS · Squirrel

1. أيقونة Squirrel في شريط القوائم → **بيانات المستخدم…** لفتح `~/Library/Rime/`. إن لم يوجد `squirrel.custom.yaml` فأنشئه؛ الجذر يجب أن يكون `patch:`.
2. افتح [`schemes/xxd.squirrel.yaml`](schemes/xxd.squirrel.yaml) في هذا المستودع.
3. انسخ كتل `xxd_*` تحت `preset_color_schemes:` — زوج واحد (`xxd_tiffany` و `xxd_tiffany_night`) أو عدة أزواج أو كلها.
4. الصق تحت `patch:` → `preset_color_schemes:` في `squirrel.custom.yaml`. **أبقِ السمات الأخرى و app_options.**
5. اكتب الزوج النشط تحت `patch:`:

```yaml
patch:
  style/color_scheme: xxd_tiffany
  style/color_scheme_dark: xxd_tiffany_night
```

6. قائمة Squirrel → **إعادة النشر**. مظهر النظام الفاتح/الداكن يستخدم هذا الزوج. للتبديل غيّر الاسمين إلى مفاتيح الجدول أدناه.

### Windows · Weasel

نفس الخطوات، الملف `%APPDATA%\Rime\weasel.custom.yaml` والألوان من [`schemes/xxd.weasel.yaml`](schemes/xxd.weasel.yaml) (BGR كما هي). ثم قائمة Weasel → إعادة النشر.

## نصوص جاهزة لمساعد الذكاء الاصطناعي

انسخ أحد النصوص التالية إلى Cursor أو Claude أو ChatGPT أو Grok. بدّل اسم اللوحة ومفاتيح `xxd_`. **ممنوع الرابط الرمزي و `__include`.**

### تثبيت الكل وتفعيل تيفاني

```
ثبّت كل لوحات XXD لـ Squirrel على macOS من https://github.com/nevertoday/rime-color-scheme
لا تستخدم رابطاً رمزياً ولا __include.
انسخ كل مخططات xxd_* من schemes/xxd.squirrel.yaml إلى patch.preset_color_schemes في ~/Library/Rime/squirrel.custom.yaml.
أبقِ المخططات و app_options ومفاتيح patch الأخرى الموجودة.
عيّن:
style/color_scheme: xxd_tiffany
style/color_scheme_dark: xxd_tiffany_night
ثم نفّذ:
"/Library/Input Methods/Squirrel.app/Contents/MacOS/Squirrel" --reload
عند الانتهاء أدرج مفاتيح xxd_ التي كتبتها.
```

### تثبيت لوحة واحدة (غيّر الاسم والمفاتيح)

```
ثبّت لوحة XXD «أزرق تيفاني» فقط لـ Squirrel على macOS.
المستودع: https://github.com/nevertoday/rime-color-scheme
انسخ فقط xxd_tiffany و xxd_tiffany_night من schemes/xxd.squirrel.yaml إلى preset_color_schemes في ~/Library/Rime/squirrel.custom.yaml.
لا رابط رمزي ولا __include ولا تحذف مخططاتي الأخرى.
تفعيل:
style/color_scheme: xxd_tiffany
style/color_scheme_dark: xxd_tiffany_night
ثم Squirrel --reload.
```

### تثبيت عدة لوحات وتفعيل واحدة

```
من https://github.com/nevertoday/rime-color-scheme schemes/xxd.squirrel.yaml
انسخ هذه إلى ~/Library/Rime/squirrel.custom.yaml:
xxd_hermes, xxd_hermes_night, xxd_klein, xxd_klein_night, xxd_chanel, xxd_chanel_night
فعّل هيرميس:
style/color_scheme: xxd_hermes
style/color_scheme_dark: xxd_hermes_night
لا رابط رمزي ولا __include، أبقِ بقية الإعداد. انشر Squirrel:
"/Library/Input Methods/Squirrel.app/Contents/MacOS/Squirrel" --reload
```

### مثبّت مسبقاً — غيّر الزوج النشط فقط

```
~/Library/Rime/squirrel.custom.yaml يحتوي xxd_* مسبقاً.
غيّر الزوج النشط فقط إلى أزرق كلاين:
style/color_scheme: xxd_klein
style/color_scheme_dark: xxd_klein_night
ثم Squirrel --reload. لا تعدّل preset_color_schemes. لا رابط رمزي.
```

## دور هذا المستودع

هذا المستودع حزمة الألوان وصور المعاينة. الإعداد الحي هو `squirrel.custom.yaml` على جهازك. بعد تعديل YAML هنا، انسخه إلى مجلد Rime وانشر.

أصفر ايكيا وشارتروز يختفيان على الورق الأبيض، لذا يستخدم الوضع الفاتح شريطاً كحلياً / كاكياً خلف شريحة العلامة. ليلي شانيل شريط فحمي + شريحة سوداء + نص عاجي. لون النص: أبيض على الشرائح الداكنة، وحبر من العائلة نفسها على الشرائح الفاتحة (تيفاني `#0A7680`، المرجان `#742C25`، الألفية `#783639`).

صور المعاينة يولدها `python3 scripts/render_previews.py` من YAML. لا ترسمها يدوياً.
